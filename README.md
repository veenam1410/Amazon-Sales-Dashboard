# 📊 Amazon Sales Dashboard

An interactive **Amazon Sales Dashboard** built in **Microsoft Excel** to analyze sales performance, customer behavior, product ratings, shipping trends, and payment preferences. This dashboard transforms a large e-commerce dataset into meaningful business insights using dynamic KPIs, Pivot Tables, Pivot Charts, Power Query, and interactive slicers.

---

## 📌 Project Description

This project demonstrates the end-to-end process of building a professional Excel dashboard for business reporting. Starting with a raw Amazon sales dataset, the data was cleaned and transformed using **Power Query**, followed by the creation of analytical KPIs and interactive visualizations.

The dashboard enables users to filter data by **Product Category**, **Year**, and **City**, providing a dynamic view of sales performance and operational metrics.
